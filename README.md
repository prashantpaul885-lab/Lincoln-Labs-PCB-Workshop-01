# Lincoln-Labs-PCB-Workshop-01
This is a 2-layer PCB for a 555 timer LED blinker, designed in EasyEDA. An NE555P runs in astable mode with R1 (1k), R2 (100k) and C1 (10µF) setting a blink rate of about 0.72 Hz. R3 (220Ω) limits the LED current, C2 (10nF) filters pin 5, and a 5V DC jack powers the board.
